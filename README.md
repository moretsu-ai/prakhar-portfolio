# Prakhar Dewangan — Portfolio
1. Edit all text, links, skills, projects settings and contact details in `content.js` (photos live in `assets/`).
2. Run locally: `python3 -m http.server 8000`, then open http://localhost:8000.
3. Push: `git remote add origin https://github.com/moretsu-ai/prakhar-portfolio.git && git push -u origin main`.
4. Deploy on Vercel: Import the repo, choose Framework Preset "Other", no build command, output directory `./`.
5. Contact form: add a free Web3Forms access key to `contact.web3formsKey` (empty = mailto fallback).
